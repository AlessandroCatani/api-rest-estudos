# Task Manager API

Projeto de estudo de API REST com Python (FastAPI) e PostgreSQL.

Permite que usuários se cadastrem, autentiquem via JWT e gerenciem seus
próprios projetos e tarefas.

## Stack

- FastAPI
- PostgreSQL + SQLAlchemy + Alembic
- JWT (autenticação)
- Pytest (testes)
- Docker Compose
